# naiver_stoke_pinnsformer_pra.ipynb — 参数说明

所有可调超参数集中在 **Cell 1**，修改后无需改动下游代码。

## 数据参数

| 参数 | 当前值 | 说明 | 建议范围 |
|------|--------|------|---------|
| `N_TRAIN` | 800 | 从 N×T (~1M) 个可用点中随机采样的训练点数。值越大精度越高，但显存消耗也越大 | 12GB 显存 ≤800；24GB 显存可恢复 2500 |
| `NUM_SEQ` | 5 | 伪时间序列长度，即每个输入点扩展为几个时间步 | 3 ~ 5 |
| `SEQ_STEP` | 1e-2 | 伪时间序列的步长 Δt，控制相邻时间步的间隔 | 1e-4 ~ 1e-2 |

## 模型结构参数

| 参数 | 当前值 | 说明 | 建议范围 |
|------|--------|------|---------|
| `D_OUT` | 2 | 输出维度：流函数 ψ 和压力 p | 固定为 2 |
| `D_MODEL` | 32 | Transformer 嵌入维度，所有 attention 和 FFN 的内部表示维度 | 16 ~ 64 |
| `D_HIDDEN` | 512 | 最终输出头的隐层维度 | 256 ~ 512 |
| `D_FF` | 256 | FeedForward 网络内部的隐层维度 | 128 ~ 512 |
| `N_LAYERS` | 1 | Encoder 和 Decoder 各自堆叠的层数 | 1 ~ 3 |
| `N_HEADS` | 2 | 多头注意力的头数，必须能整除 D_MODEL | 2 ~ 4 |

## 训练参数

| 参数 | 当前值 | 说明 | 建议范围 |
|------|--------|------|---------|
| `N_EPOCHS` | 1000 | LBFGS 最大迭代次数 | 500 ~ 2000 |
| `OPTIMIZER` | LBFGS | 优化器选择。LBFGS 收敛快但显存大；Adam 省显存但收敛慢 | `'LBFGS'` 或 `'Adam'` |
| `LINE_SEARCH` | strong_wolfe | LBFGS 线搜索策略。设为 `None` 可省显存但可能影响收敛 | `'strong_wolfe'` 或 `None` |

## PDE 参数

| 参数 | 当前值 | 说明 | 建议范围 |
|------|--------|------|---------|
| `NU` | 0.01 | Navier-Stokes 方程中的粘度系数 ν | 由物理问题决定 |

## 评估参数

| 参数 | 当前值 | 说明 | 建议范围 |
|------|--------|------|---------|
| `TEST_SNAP` | 100 | 测试时使用的时间快照索引（T 共 200 帧） | 0 ~ 199 |

## 数据集格式

文件：`cylinder_nektar_wake.mat`（22.9 MB）

来源：Nektar++ 谱元法 DNS 模拟 — Re=100 二维圆柱绕流

### MAT 文件变量

| 变量 | 形状 | 类型 | 物理含义 | 数值范围 |
|------|------|------|---------|---------|
| `X_star` | (5000, 2) | float64 | 5000 个非结构化网格点的 (x, y) 坐标 | x∈[1.0, 8.0], y∈[-2.0, 2.0] |
| `t` | (200, 1) | float64 | 200 个均匀时间步 | t∈[0.0, 19.9], Δt=0.1 |
| `U_star` | (5000, 2, 200) | float64 | 速度场 [u, v] 在全部时空点的值 | u∈[-0.24, 1.32], v∈[-0.62, 0.62] |
| `p_star` | (5000, 200) | float64 | 压力场在全部时空点的值 | p∈[-0.54, 0.07] |

### 各变量详解

#### U_star — 速度场三维数组 (5000, 2, 200)

```
U_star[空间点, 速度分量, 时间步]
       ↑        ↑         ↑
     5000个     2个      200帧
   (网格点)  (u/v)   (时间序列)
```

| 索引方式 | 结果形状 | 含义 |
|----------|---------|------|
| `U_star` | `(5000, 2, 200)` | 全部数据 |
| `U_star[:, 0, :]` | `(5000, 200)` | 所有点、u 分量、所有时间 |
| `U_star[:, 1, :]` | `(5000, 200)` | 所有点、v 分量、所有时间 |
| `U_star[0]` | `(2, 200)` | 第0个点，两个速度分量所有时间 |
| `U_star[0][0]` = `U_star[0, 0]` | `(200,)` | 第0个点的 u 分量（所有200帧） |
| `U_star[0, 0, 0]` | 标量 | 第0个点、u 分量、第0时间步的值 |

**直观类比**：一本 5000 行 × 2 列 × 200 页的书，每页是一个时间帧的二维流场快照。

#### X_star — 空间坐标二维数组 (5000, 2)

X_star 的处理经历了 **5 个阶段**：

```
X_star (5000, 2)                     原始：5000个网格点的 (x,y)
  │
  ├── X_star[:, 0:1]                拆分：单独抽 x 列 (5000,1)
  └── X_star[:, 1:2]                拆分：单独抽 y 列 (5000,1)
        │
        ▼  np.tile(..., (1, 200))
  XX (5000, 200)                    网格化：每列复制200份 = 时空网格
  YY (5000, 200)
        │
        ▼  .flatten()[:, None]
  x (1000000, 1)                    展平：按行展开为列向量
  y (1000000, 1)
        │
        ▼  [idx, :]
  x_train (800, 1)                  采样：随机抽取 N_TRAIN 个点
  y_train (800, 1)
        │
        ▼  np.tile + np.expand_dims
  x_train (800, 5, 1)               序列化：复制5份 → 伪时间序列
  y_train (800, 5, 1)
```

> **关键**：x, y 在序列维度上值不变（空间坐标不随时间改变），只有 t 维度在变化。

#### np.tile 详解

`np.tile(arr, reps)` = 沿各维度复制数组 arr。

```python
XX = np.tile(X_star[:, 0:1], (1, T))
#             ↑                 ↑
#        (5000, 1) x 列    沿 dim0×1, dim1×T=200
#
#  输入:  [[x₀],          输出:  [[x₀, x₀, ..., x₀],    ← 200个相同的x₀
#          [x₁],                  [x₁, x₁, ..., x₁],
#          ...                    ...
#          [x₄₉₉₉]]              [x₄₉₉₉, x₄₉₉₉, ..., x₄₉₉₉]]
#         (5000, 1)                        (5000, 200)
```

**为什么需要 tile？** 每个空间点的 (x,y) 坐标在所有 200 个时间步上相同，tile 就是把这个不变性"展开"成网格。

**x, y, t 三种 tile 对比**：

```python
XX = np.tile(X_star[:,0:1], (1, 200))   # x: 沿时间维复制 → 同行值相同
YY = np.tile(X_star[:,1:2], (1, 200))   # y: 同上
TT = np.tile(t_star, (1, 5000)).T        # t: 沿空间维复制 → 同列值相同
#                   ↑ 注意转置!
```

### 数据预处理流程

#### 完整5步流程

```
原始数据                    展平后                      采样后                    伪时间序列
─────────────────────────────────────────────────────────────────────────────────────────────
X_star (5000,2)  ─┐
t      (200,1)   ─┤  拼接    x (1M, 1)            x_train (N_TRAIN, 1)     x_train (N_TRAIN, NUM_SEQ, 1)
                  ─┤  ────→   y (1M, 1)   ──采样──→  y_train (N_TRAIN, 1)  ──扩展──→  y_train (N_TRAIN, NUM_SEQ, 1)
U_star (5000,2,200) ┤          t (1M, 1)            t_train (N_TRAIN, 1)     t_train (N_TRAIN, NUM_SEQ, 1)
p_star (5000,200)   ┘          u (1M, 1)            u_train (N_TRAIN, 1)     保持原样
                                v (1M, 1)            v_train (N_TRAIN, 1)     保持原样
                                p (1M, 1)

展平: np.tile + flatten → N*T = 1,000,000 个时空点
采样: np.random.choice(N*T, N_TRAIN, replace=False)
扩展: make_time_sequence(t, num_step=NUM_SEQ, step=SEQ_STEP) → [t, t+Δt, t+2Δt, t+3Δt, t+4Δt]
       x, y 在序列维度上复制（值不变），u_train, v_train 保持 2D（作为标签）
```

### 多维度对照

| 阶段 | x 形状 | t 形状 | u/v 形状 | 说明 |
|------|--------|--------|----------|------|
| 原始 | (5000,2) | (200,1) | (5000,2,200) | 结构化时空网格 |
| 展平 | (1M, 1) | (1M, 1) | (1M, 1) | 所有点展开为列向量 |
| 采样 | (N_TRAIN, 1) | (N_TRAIN, 1) | (N_TRAIN, 1) | 随机采样减少计算量 |
| 序列化 | (N_TRAIN, NUM_SEQ, 1) | (N_TRAIN, NUM_SEQ, 1) | (N_TRAIN, 1) | 伪时间序列 + 标签保持原样 |
| GPU Tensor | (N_TRAIN, NUM_SEQ, 1) | (N_TRAIN, NUM_SEQ, 1) | (N_TRAIN, 1) | requires_grad=True for x,y,t |

## 模型输入输出

### 前向传播

```
输入:  x (N, NUM_SEQ, 1)     — 空间坐标 x
       y (N, NUM_SEQ, 1)     — 空间坐标 y
       t (N, NUM_SEQ, 1)     — 伪时间序列 [t, t+Δt, ..., t+(k-1)Δt]

拼接:  torch.cat((x,y,t), dim=-1) → (N, NUM_SEQ, 3)

输出:  model(x,y,t) → (N, NUM_SEQ, 2)
       ├── channel 0: ψ (流函数)   — 速度由自动微分求出
       └── channel 1: p (压力)     — 直接输出
```

### 训练时的物理量推导（链式自动微分）

```
模型输出 ψ, p
  │
  ├── u = ∂ψ/∂y           ← 第 1 次 grad: psi → y_train
  ├── v = -∂ψ/∂x          ← 第 2 次 grad: psi → x_train
  │
  ├── u_t, u_x, u_y       ← 第 3-5 次 grad: u → t,x,y
  ├── u_xx, u_yy          ← 第 6-7 次 grad: u_x → x, u_y → y
  ├── v_t, v_x, v_y       ← 第 8-10 次 grad
  ├── v_xx, v_yy          ← 第 11-12 次 grad
  ├── p_x, p_y            ← 第 13 次 grad: p → x,y
  │
  └── 组装 N-S 方程残差:
      f_u = u_t + u·u_x + v·u_y + p_x - ν(u_xx + u_yy)
      f_v = v_t + u·v_x + v·v_y + p_y - ν(v_xx + v_yy)
```

### 损失函数

```
loss = mean[(u_pred[:,0] - u_true)²]    ← 数据约束 (序列第 0 步 = 原始时间)
     + mean[(v_pred[:,0] - v_true)²]    ← 数据约束
     + mean[f_u²]                        ← x-动量方程残差
     + mean[f_v²]                        ← y-动量方程残差
```

### 评估时的输出

```
测试输入: (N=5000, NUM_SEQ, 3)   — 全部 5000 个空间点，单时间快照 TEST_SNAP

模型输出:
  psi   (5000, NUM_SEQ, 1)     → u_pred = ∂ψ/∂y, 取[:,0] → (5000,)  ← 第 0 个时间步
  p_pred (5000, NUM_SEQ, 1)    → 取[:,0] → (5000,)

评估指标:
  error_u = ∥u_pred - u_true∥₂ / ∥u_true∥₂
  error_v = ∥v_pred - v_true∥₂ / ∥v_true∥₂
  error_p = ∥p_pred - p_true∥₂ / ∥p_true∥₂
```

## 显存不足时的调整优先级

1. **先降 `N_TRAIN`**（影响最大，从 2500 → 800 → 500）
2. 降 `NUM_SEQ`（5 → 3）
3. 设 `LINE_SEARCH = None`（关闭 LBFGS 线搜索）
4. 换 `OPTIMIZER = 'Adam'`（牺牲速度换显存）
5. 降 `D_HIDDEN`（512 → 256）
