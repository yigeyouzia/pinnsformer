# Navier–Stokes notebook index

Notebooks are grouped by method so experiments can be compared and handed off cleanly.

- `adam/` — simple-sum Adam baseline
- `config/` — ConFIG and multi-seed/4-loss ConFIG experiments
- `mconfig/` — M-ConFIG variants
- `autobalance/` — AutoBalance
- `harmonic/` — HARMONIC-4
- `chebyshev/` — Chebyshev-center p=2/p=4
- `analysis/` — diagnostics, dataset exploration, and plotting

Shared canonical Python modules remain in `pinnsformer-config/` rather than being copied into each method folder.
